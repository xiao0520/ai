# 服饰企业合同智能体功能与技术方案

> 更新日期：2026-10-19  
> 适用范围：自主研发、自有工厂、服饰零售。以日常合同处理为目标，优先复用现有 mjn-ai 项目。

## 一、建设目标

建设一个实用的合同智能助手，帮助业务和法务完成合同审查、修改、起草、问答和查询，提高处理效率，统一审查标准。

功能以常用场景为主，先完成可用版本，再根据实际使用情况补充集成能力。

## 二、核心功能：按重要程度排序

P0 为首期必备，P1 为常用增强。解析、权限和知识基础按开发依赖先行建设。

| 优先级 | 功能 | 核心内容 |
|---|---|---|
| P0 | 1. 智能审查 | 按合同类型和我方立场，识别风险、缺失条款、前后矛盾及公司规则偏差 |
| P0 | 2. 解析与信息提取 | 支持 Word、PDF 及扫描件，提取主体、金额、期限、交期和付款等信息 |
| P0 | 3. 修改建议与报告 | 展示风险原文、依据、建议条款，支持人工确认和审查报告导出 |
| P0 | 4. 企业知识与规则 | 维护公司制度、合同模板、标准条款和分类审查要点，为 AI 提供依据 |
| P0 | 5. 合同记录与查询 | 保存原文件、版本和审查结果，支持列表查询、访问权限和操作记录 |
| P1 | 6. 版本对比与修订 | 高亮两版合同的差异，重点提示金额、责任、日期变化，支持 Word 批注或修订稿 |
| P1 | 7. 模板起草 | 填写业务信息，基于已批准模板生成合同，提示未填写事项 |
| P1 | 8. 合同问答 | 围绕当前合同及公司规则回答问题，并引用原文依据 |

审查意见区分法律要求、公司制度和商业偏好；依据不足时提示人工核实。

**按需接入的能力**：合同到期提醒、现有审批/电子签章、通过 MCP 查询必要业务数据。是否建设由实际使用需求决定。

**本次暂不纳入**：复杂经营分析、自动对账结算、自动谈判签署、多智能体协作及全生命周期流程重建。

## 三、重点合同场景

优先适配面辅料采购、门店租赁/商场联营和人事合同三类场景，共用同一套功能，只配置不同的提取字段和审查要点。

| 合同类型 | 重点关注 | 主要输出 |
|---|---|---|
| 面辅料采购 | 材料规格、质量与验收、价格、交期、退换及付款 | 采购要素摘要、条款缺漏、风险及修改建议 |
| 门店租赁/商场联营 | 租期、免租期、租金或扣点、费用、保证金及退出条件 | 费用与期限摘要、不利条款及修改建议 |
| 人事合同 | 劳动合同、保密及竞业协议中的期限、试用期、岗位薪酬、工时、解除条件及补偿约定 | 用工要素摘要、条款缺漏、风险及修改建议 |

设计/IP 授权作为按需补充，重点检查成果归属、保密和授权范围。自有工厂内部的排产、领料和生产工单继续由原业务系统处理。

## 四、技术栈：复用现有项目

| 层次 | 项目已有技术 | 用途 |
|---|---|---|
| 前端 | Vue 3、TypeScript；用户端 Element Plus，管理端 Vben/Ant Design Vue | 合同上传、审查展示、记录查询和规则维护 |
| 业务后台 | Java、Spring Boot、MyBatis-Plus、Sa-Token | 合同记录、权限、业务接口和操作留痕 |
| AI 服务 | Python、FastAPI、LangChain、LangGraph、现有模型管理与适配 | 组织解析、检索、审查和结果校验 |
| RAG | Qdrant、向量与 BM25 混合检索、重排序 | 检索公司制度、标准条款和参考案例 |
| MCP | LangChain MCP 接入、独立 FastMCP 服务 | 按需连接经过授权的业务查询工具 |

**现有基础**：代码已有合同上传、提取、RAG 检索、风险审查和结果查看；合同流程尚未接入 MCP 业务查询，独立 MCP 服务目前提供可选 ERP 示例工具。此为代码核对结果，生产部署和业务效果仍需验证。

**需要补充**：OCR、分类审查规则、合同列表、人工反馈、报告导出，以及后续的对比修订和模板起草。优先复用已有服务，确有缺口再选组件；保留现有任务机制。

## 五、Agent、RAG 与 MCP 的结合

| 能力 | 在智能体中的作用 | 本项目做法 |
|---|---|---|
| Agent | 组织任务步骤，调用所需能力，汇总结果 | 沿用单个合同智能体和固定 LangGraph 流程 |
| RAG | 给审查和问答提供企业知识依据 | 智能体直接调用现有授权检索，获取内容及来源 |
| MCP | 让智能体查询业务系统中的必要数据 | 有明确需求时扩展 FastMCP 工具，例如查询采购订单 |

**基本流程**：上传合同 → 解析与提取 → RAG 检索规则 → AI 审查 → 结果校验 → 人工复核与导出。

例如，审查面料采购合同时，RAG 提供采购制度和质量条款；需要核对订单价格、交期时，再由智能体通过 MCP 查询授权订单数据，并将差异纳入审查结果。

RAG 可作为智能体直接调用的能力，也可封装为 MCP 工具；本项目保留现有直接调用方式。MCP 按需加入流程，不是每次审查的必经步骤。

## 六、实施与验收

| 阶段 | 建设内容 | 交付标准 |
|---|---|---|
| 首期可用 | 补齐 P0，适配重点合同类型 | 能上传、审查、查看依据、导出报告及查询历史记录 |
| 常用增强 | 版本对比、修订、模板起草及合同问答 | 能处理日常改稿、起草和咨询 |
| 按需接入 | 到期提醒、审批签章或必要 MCP 查询 | 对明确需求完成接入和验证，不预设全面扩展 |

使用脱敏真实合同，由业务与法务核对：关键字段是否准确、重要风险是否漏报或误报、建议是否可用、人工处理时间是否减少。保留权限校验和人工复核。
